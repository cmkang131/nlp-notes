경사 하강법의 방향과 수렴

업데이트 식과 gradient 부호 퀴즈

  • 복습 : 모델 학습 = weight(가중치) 조정 → 예측과 정답의 차이 loss(손실) 필요
    • 회귀는 squared error, 분류는 negative log-likelihood
  • 이 슬라이드 : loss를 줄이는 방향으로 weight를 고치는 업데이트 식 + loss 곡선
  • : 학습률(learning rate)
  • : 곡선 위 그 지점의 기울기
  • learning rate는 학습으로 구하지 않음 → 사람이 정하는 hyperparameter
    • development set 성능을 보고 직접 조정
  • 퀴즈 : 가 최소점 오른쪽일 때 기울기의 부호? → positive (접선이 오르막)
    • 최소점 오른쪽 : 기울기 양수 → 감소 → 왼쪽 (최소점 쪽)으로 이동
    • 최소점 왼쪽 : 기울기 음수 → 증가 → 오른쪽 (최소점 쪽)으로 이동

이동 방향과 수렴

  • 이동량 = → 가 그만큼 옮겨져
  • 마이너스 부호 → loss가 줄어드는 쪽 = gradient descent(경사 하강법)
    • 부호를 반대로 하면 loss가 커지는 gradient ascent
  • 이동 폭 = learning rate(학습률) × 기울기 크기
    • 가파른 곳은 크게, 평평한 곳은 작게
    • 최소점에 다가갈수록 걸음이 짧아짐 (오른쪽 슬라이드)
  • 최소점 근처 gradient ≈ 0 → 가 더는 안 움직임 = 수렴(convergence)

learning rate가 너무 크면 : 발산

  • 최소점 왼쪽에서 출발, learning rate 큼
  • 기울기 음수 → 오른쪽 이동 → 최소점을 넘어 반대편에 떨어짐 (왼쪽 슬라이드)
  • 반대편은 기울기 양수 → 왼쪽 이동 → 다시 넘어 처음보다 높은 곳에 도착 (오른쪽 슬라이드)
  • 반복 → loss가 줄지 않고 커짐 = 발산(divergence)
  • 적절한 learning rate여야 최소점으로 수렴 → 손계산으로 확인

learning rate 크기와 학습의 어려움

너무 작으면 : 학습이 느림

  • 걸음이 짧아 최소점까지 오래 걸림 (슬라이드 : "Learning is too slow!")
  • 발산을 피하겠다고 무작정 작게 잡으면 학습 시간이 한없이 늘어남

local minimum에 빠지는 문제

  • 실제 loss 곡선은 우묵한 곳이 여러 개일 수 있음
    • global minimum : 전체에서 가장 낮은 점
    • local minimum(국소 최솟값) : 주변보다만 낮은 점
  • 왼쪽 : learning rate가 작음 → 가까운 local minimum에서 멈춤
    • gradient = 0 → 업데이트가 weight를 못 움직임
    • 작은 learning rate가 원인이 되기도 함
  • 오른쪽 : 처음 큰 걸음으로 언덕을 넘고, 걸음이 줄며 global minimum에 안착
  • 개념적인 그림일 뿐 : loss landscape를 미리 알 수 없음 → 그렇게 되기를 기대하며 조절

GD, SGD, mini-batch GD

세 가지 업데이트 방식

  • → GD, → SGD, mini-batch는 그 사이

forward와 backward propagation

한 번의 학습 단계

  • 슬라이드 : 파란 화살표(입력 → 은닉층 → 출력 ), 빨간 화살표(loss 에서 거꾸로)
  • forward propagation(순전파) : 입력에서 출력 쪽으로 계산해 와 loss를 구함
  • backward propagation(backpropagation) : loss에서 거슬러 올라가며 chain rule로 gradient를 구하고 weight를 업데이트
  • 학습 = mini-batch마다 forward(loss) → backward(weight 수정)를 반복
  • 앞 시간 : 은닉층 있는 네트워크의 chain rule(연쇄 법칙) 예 → 이번 손계산은 가장 단순한 형태
  • 수업 앞부분 : 학습 과정 코드의 빈칸 채우기 실습
    • 같은 데이터·과제에 더 큰 네트워크 → 더 빨리 수렴 (parameter가 많아 표현력이 큼)
    • 이 과제는 어렵지 않음

다중 클래스 분류 : softmax

sigmoid 대신 softmax

  • class가 셋 이상 → 출력 노드도 class 수만큼
  • 출력을 확률로 만들려면 합이 1이 되도록 정규화 → softmax(소프트맥스)
  • : i번째 class의 점수(logit)
  • 분모 : 모든 class의 값의 합 (슬라이드는 class 셋 → 부터 2)
  • 모든 출력이 양수, 합이 1, 점수가 큰 class가 큰 확률
  • 오른쪽 슬라이드 예 : 출력 0.1, 0.7, 0.2
    • 추론(inference) 때 가장 높은 확률의 노드를 예측으로 고름

underfitting과 overfitting

  • 슬라이드 : 점 = 데이터, 곡선 = 모델
  • underfitting(과소적합) (오른쪽) : 아무것도 못 배움 → 곡선이 수평선에 가까워 경향을 못 따라감
  • overfitting(과적합) (왼쪽) : training set에 과하게 맞춤 → 곡선이 모든 점을 지나도록 꾸불꾸불
    • 개별 샘플을 외워서 푼 것 → 새 샘플에 약함
  • optimum (가운데) : 둘 사이, training 오차가 조금 남아도 test set에 잘 맞음
  • underfitting / optimum / overfitting
    • 학습 데이터 오차 : 큼 / 조금 남음 / 매우 작음
    • 새 데이터 오차 : 큼 / 작음 / 큼
    • 모델의 모습 : 아무것도 못 배움 / 경향을 잡음 / 샘플을 외움
    • 곡선 : 수평에 가까움 / 완만함 / 꾸불꾸불
  • overfitting을 줄이는 방법 : L2 regularization(정규화), dropout(드롭아웃)

L2 regularization

  • weight가 크면 너무 expressive → 개념 이해 없이 샘플을 하나씩 외움
  • weight를 작게 유지하려고 cost function에 weight 제곱합을 추가
  • : 원래의 loss
  • : regularization 세기를 정하는 hyperparameter
  • : 훈련 샘플 수, 합은 모든 weight 에 대해
  • weight가 클수록 cost 증가 → weight를 줄이는 압력
  • 미분
  • 업데이트 식에 넣으면 weight decay 형태
  • 에 1보다 약간 작은 수 을 곱한 뒤 평소 gradient 업데이트
    • 현재의 가 이 항으로 줄어듦
  • 계산 예 : , ,

dropout

  • dropout : 학습 중 각 뉴런을 확률 로 꺼서(disable) activation을 안 씀
  • 오른쪽 슬라이드 : 은닉 뉴런 12개 중 6개에 X 표시
  • → 평균 절반의 뉴런이 무작위로 꺼짐
  • 꺼지는 뉴런이 매번 달라짐 → 어떤 뉴런도 training set의 특정 값을 못 외움
  • 추론 시에는 dropout을 끄고 전체 뉴런 사용
  • L2 regularization vs dropout
항목 L2 regularization dropout
건드리는 곳 cost에 weight 제곱합 항 추가 학습 중 뉴런을 확률 로 끔
효과 weight가 작아져 덜 expressive 특정 뉴런이 샘플을 못 외움
hyperparameter
학습 중 동작 매 업데이트에서 에 곱함 반복마다 다른 뉴런 집합을 끔
추론 학습된 작은 weight 그대로 전체 뉴런 사용
