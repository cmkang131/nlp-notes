AI, ML, DL의 정의

AI : 사람처럼 생각하고 행동하는 프로그램 = 사람의 지능을 흉내(mimic)
  • 만드는 방법은 정의에 없음 → 규칙으로 만든 시스템도, 데이터로 학습한 시스템도 AI
ML (machine learning) : 데이터를 소비하며 모델이 스스로 파라미터를 조정하는 방법
  • 예전엔 사람이 기계의 행동 규칙(rule)을 만들어 줌
  • 세상이 다양하고 계속 변함 → 새 규칙이 매일 생김 → 사람이 다 만들 수 없음
  • 그래서 모델이 입력·출력 데이터로 스스로 배움
  • 사람은 모델 형태와 학습 절차만 정함 → 규칙에 해당하는 파라미터는 데이터가 정함
DL (deep learning) : neural network로 구현한 ML (ML의 subset)
  • deep = input과 output 사이에 hidden layer가 여러 겹
  • 구조·학습법은 뒤 강의에서 다룸

항목AIMLDL

등장 이유사람 지능을 흉내규칙을 다 못 만듦층이 여러 개인 신경망

NLP의 위치

NLP는 그림의 어디쯤인가

학생들은 DL 영역 안쪽을 가리킴 → 기본적으로는 맞음

하지만 NLP는 DL보다 넓은 영역을 덮음

  • 예전엔 텍스트를 symbol(사람이 만든 기호·규칙)로 처리
  • DL이 아닌 순수 ML로 처리하던 시기도 있었음
  • 요즘은 텍스트·음성을 DL로 처리
  • 때로 심리·정신 과정(psychological, mental process)까지 포함

접근별 텍스트를 다루는 방식 → 이 수업에서 만나는 곳

  • symbol 기반 (규칙 기반) : 사람이 만든 기호·규칙 → 정규표현식, 규칙 기반 tokenizer
  • 순수 ML : 신경망 없이 데이터에서 통계적으로 학습 → n-gram LM, 나이브 베이즈
  • DL : 신경망으로 텍스트·음성 처리 → 신경망, RNN, LSTM/GRU, Transformer, BERT, GPT

앞 방식이 완전히 사라진 것은 아님 → 규칙 기반 tokenizer와 transformer를 함께 다룸

수업 범위 : 기초적인 규칙 기반 tokenizer → transformer 같은 DL 모델

심리·정신 과정은 다루지 않음

앞으로 다룰 모델 흐름

1강은 이름과 역할만 소개 → 동작 원리는 이후 수업

인공신경망과 RNN

인공신경망 : 뉴런에 input → output, 이런 층을 여러 겹 쌓으면 deep learning

RNN (recurrent neural network) : 시계열(time series) 데이터 처리에 좋은 구조

텍스트도 시계열 → 순서(order)가 있음

  • I like a dog : I가 첫 번째, like가 두 번째
  • "개가 사람을 문다" vs "사람이 개를 문다" → 같은 단어, 반대 뜻

단어를 순서대로 하나씩 읽으며 지금까지 읽은 내용을 상태로 들고 감

가장 단순한 기본형 = vanilla RNN

LSTM과 GRU

LSTM (Long Short-Term Memory) : vanilla RNN의 개선판, unit 내부에 복잡한 상호작용
GRU (Gated Recurrent Unit) : 또 다른 기법, LSTM과 독립적으로 발명 → 동작 원리는 비슷

구조는 외울 필요 없음 → 동작 이해가 목표 (다음 수업)

공통 목표 : 단순 RNN은 문장이 길면 앞쪽 정보를 잘 유지 못 함 → 무엇을 기억하고 버릴지 조절하는 gate를 둠

Transformer, BERT, GPT

Transformer : 요즘 대부분의 프로젝트가 쓰는 구조, 매우 강력하지만 크고 무거움(big, heavy)

BERT와 GPT 모두 transformer 기반

BERT : masked LM, Bidirectional Encoder Representations from Transformers
  • 긴 문맥(long context)을 처리하며 처음 도입된 구조 중 하나
  • 입력의 임의 토큰 몇 개를 mask 토큰으로 바꿈 → 모델이 원래 토큰을 예측 → 반복하며 문맥을 이해
  • 가려진 토큰을 맞히려면 주변 단어가 단서 → 과제를 푸는 것이 곧 문맥을 읽는 능력
  • 예 : I like a dog → I like a [MASK] → 정답 dog
GPT : Generative Pre-trained Transformer
  • 문맥(context)이 주어지면 다음 토큰(next token)을 하나씩 생성
  • 생성한 토큰이 다시 문맥에 합쳐짐 → 다음 토큰 생성 반복
  • 예 : 문맥 I like a → 다음 토큰 dog

BERT vs GPT

항목BERTGPT
기반 구조둘 다 transformer둘 다 transformer
학습 과제일부 토큰을 mask로 바꾸고 원래 토큰 예측주어진 문맥 다음 토큰 예측
사용하는 문맥가려진 자리의 앞과 뒤 모두이미 나온 앞쪽만
주된 용도문장 이해, 분류텍스트 생성

RAG

RAG : Retrieval-Augmented Generation

출발점 : LLM이 모든 정보를 갖고 있지는 않음 → 인터넷, DB, 문서 같은 외부 정보가 필요할 때가 있음

흐름 : 질문 → 외부 DB에서 근거(evidence) 검색 → 근거를 context로 함께 LLM에 줌 → LLM이 답 생성

수업 후반부에 아주 간단히 다룰 예정

NLP의 대표 응용

번역, 독해, 대화

기계 번역 (machine translation) : 원문(source) 입력 → 목표 언어 문장(target) 생성
  • 수업 예 : 영어 → 프랑스어
  • 어순·표현이 언어마다 다름 → 단어를 하나씩 치환하는 방식으로는 안 풀림
독해 (reading comprehension) : 문단 + 질문 → 모델이 답
  • open book Q&A와 같은 형태 : 답의 근거가 입력으로 같이 주어짐
  • RAG가 근거를 찾아 context로 붙이는 구도와 비슷
대화 (conversation) : NLP에서 매우 중요한 응용
  • 기계를 발명하는 궁극적 목적 = 사람이 기계와 상호작용하는 것
  • 언어는 그 상호작용에 유연하고 효율적인 수단 → LLM이 인기를 얻은 이유도 같음

요약 (text summarization)

abstractive : 문서 전체를 이해 → 내부적으로 요약 → 요약문을 토큰 하나씩 생성
extractive : 핵심 구·핵심 문장을 뽑아 이어 붙여 요약문으로 사용

abstractive vs extractive

항목abstractiveextractive
요약문새로 생성원문의 구·문장을 그대로 사용
원문에 없는 표현쓸 수 있음안 씀
필요한 능력문서 이해 + 텍스트 생성무엇이 중요한지 고르는 판단
생기기 쉬운 문제원문에 없는 내용을 지어낼 위험문장 사이 연결이 어색
요약 예
원문 : 이 수업은 정규표현식으로 시작한다. 이어서 n-gram 언어 모델을 배운다. 마지막으로 신경망과 transformer를 다룬다.
extractive : 마지막으로 신경망과 transformer를 다룬다. (원문 문장 선택)
abstractive : 이 수업은 규칙 기반 방법에서 신경망 모델로 나아간다. (새로 생성)

멀티모달 학습과 embodied AI

멀티모달 학습 (multimodal learning) : 텍스트 외에 이미지 같은 다른 종류의 입력(modality)을 함께 다룸

VQA, commonsense reasoning, captioning

VQA (visual question answering) : 이미지 + 질문 → 답
  • 사람에겐 쉽고 기계엔 어려운 문제였음 → transformer 발전과 모델 크기 확대로 지금은 매우 쉬워짐
  • 수업 예 : "이 이미지들에서 콧수염은 무엇으로 만들어졌는가" → 바나나 (답이 이미지에 보임)
commonsense reasoning : 답이 이미지에 직접 없음 → 장면의 맥락을 상상·추론
  • 수업 예 : 4번 사람이 왜 1번 사람을 가리키는가 → 이 음식이 1번 사람의 것이라는 뜻
  • 요즘은 이미지를 ChatGPT에 넣고 같은 질문을 하면 정확히 답함
image captioning : 멀티모달 학습의 기본적이고 대표적인 응용
  • 이미지가 주어지면 그 안에서 벌어지는 일을 글로 설명, 질문은 없음

embodied AI

요즘은 physical AI라고 더 자주 부름

대표 응용 : 내비게이션(navigation)

  • 긴 지시문(instruction)이 주어짐 → 시뮬레이터 안의 로봇·에이전트가 목표 상태(goal state)·위치까지 이동
  • 때로 물체와 상호작용하거나 조작(manipulate)

수업 예는 2020년의 오래된 연구

요즘은 LLM이 물체를 집고 옮기고 놓는 동작에 도움을 줄 수 있음

과제별 입력 → 출력

  • VQA : 이미지 + 질문 → 답
  • commonsense reasoning : 이미지 + 이유를 묻는 질문 → 맥락에 맞는 답
  • image captioning : 이미지 → 장면을 설명하는 글
  • embodied AI : 긴 지시문 + 시뮬레이터 → 이동·물체 조작 행동

시험 포인트

DL ⊂ ML ⊂ AI : 절대적 정답은 아니지만 보통 쓰는 설명

ML이 필요한 이유 : 규칙을 다 못 만듦 → 데이터로 파라미터를 스스로 조정

DL : neural network로 구현한 ML, deep = hidden layer 여러 개

NLP는 DL 안쪽만이 아님 : symbol 기반 → 순수 ML → DL, 심리·정신 과정까지 포함하기도 함

이 수업 범위 = 규칙 기반 tokenizer \~ transformer

RNN : 순서 있는 시계열 처리, LSTM·GRU는 개선판 (구조 암기 X, 동작 이해)

BERT : 일부 토큰을 mask로 바꾸고 원래 토큰 예측, GPT : 문맥 다음 토큰을 하나씩 생성, 둘 다 transformer

RAG : LLM 안에 모든 정보가 없음 → 외부 검색 근거를 context로 줌

요약 : abstractive(이해 후 새로 생성) vs extractive(핵심 구·문장을 뽑아 이어 붙임)

응용 : 번역, reading comprehension(open book Q&A), 대화, VQA, commonsense reasoning, image captioning, embodied AI

문제 2

다음이 맞는지 틀린지 판단하고 이유를 한 문장으로 쓰시오.

(a) DL은 ML과 별개의 분야이다.

(b) DL이 나오기 전에는 NLP라는 분야가 없었다.

(c) 이 수업은 NLP가 포함하기도 하는 심리·정신 과정까지 다룬다.

(c) 틀림 : 심리·정신 과정은 다루지 않음, 규칙 기반 tokenizer \~ transformer까지만

(d) 맞음 : 기초적인 규칙 기반 tokenizer부터 transformer 같은 DL 모델까지

문제 3

입력 문장이 I like a dog이다.

(a) BERT 방식(masked LM)으로 dog를 가릴 때 입력과 정답은?

(b) GPT 방식으로 dog를 맞힐 때 입력과 정답은?

(c) 두 방식이 공통으로 쓰는 구조와 학습 과제의 차이는?

답

(a) 입력 I like a [MASK], 정답 dog → 가려진 자리를 맞히며 문맥을 이해

(b) 입력(context) I like a, 정답 dog → 만든 토큰이 다시 문맥에 합쳐져 하나씩 이어짐

(c) 공통 구조 = transformer

  • BERT : 일부를 가리고 원래 토큰 예측
  • GPT : 문맥이 주어지면 다음 토큰을 하나씩 생성

문제 4

각 설명이 가리키는 응용 또는 기법의 이름을 쓰시오.

(a) 문단과 질문을 함께 주고 문단을 보고 답하게 한다. open book Q&A에 비유되는 과제이다.

(b) 긴 기사에서 중요한 문장 두 개를 그대로 뽑아 이어 붙여 요약문을 만든다.

(c) 기사 전체를 이해한 뒤 원문에 없는 표현으로 요약문을 토큰 하나씩 생성한다.

(d) 이미지 속 4번 사람이 왜 1번 사람을 가리키는지 묻는다. 이미지에 답이 직접 없고 맥락을 상상해야 한다.

(e) 이미지만 입력으로 주고 무슨 일이 벌어지고 있는지 글로 설명하게 한다.

(f) 질문이 들어오면 외부 DB에서 근거를 검색해 context로 함께 LLM에 주고, LLM이 그 context를 보고 답하게 한다.

답

(a) reading comprehension : 근거 문단이 입력에 함께 주어지는 open book 방식

(b) extractive summarization : 원문 문장을 그대로 선택해 이어 붙임

(c) abstractive summarization : 문서를 이해한 뒤 요약문을 새로 생성

(d) commonsense reasoning : 눈에 보이는 단서에서 의도(이 음식이 1번 사람의 것)를 추론

(e) image captioning : 질문 없이 이미지만 입력 → VQA와 다름

(f) RAG : LLM 안에 모든 정보가 없어서 외부 근거를 context로 줌
